# Reconcile Findings

The invoking Roast agent performs this judgment directly. This document does
not require a separate coordinator or synthesizer, a council envelope, or a
second review pipeline.

For each proposed finding, inspect the cited evidence, credible consequence,
relevant guards and counterevidence. Reject unsupported claims and cosmetic
preferences without a meaningful consequence. Merge duplicate root causes,
preserving distinct consequences. Do not infer correctness from agreement.

Rank supported findings by impact, not entertainment. Give each a location,
evidence, consequence, confidence, applicable standard, bounded recommendation
and observable verification. Preserve unresolved disagreement and missing
coverage. A structural validator does not prove semantic correctness.

Use only the doctrine selected for the current review, and cite each rule for
the claim it actually governs. Follow actual operator-supplied authority,
never infer a particular document's authority from its filename.

Return the current Roast finding contract. No separate executive-summary
workflow, nested report grammar, or terminator protocol applies.
